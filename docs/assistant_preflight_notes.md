## Project background summary

The project is a Minecraft Java Edition CRPG mod inspired by Disco Elysium / Esoteric Ebb. The core loop is:

`look at interactable target -> highlight -> close-range prompt -> interaction key -> dialogue/action/thought UI -> server-authoritative checks -> persistent narrative state`.

Planned stack:

- Main route: Fabric + Minecraft Java Edition 26.1.2 + JDK 25 + Java + Gradle/Fabric Loom.
- Required runtime dependencies: Fabric Loader, Fabric API, GeckoLib.
- Optional/support dependencies: YACL or Cloth Config, owo-lib, SmartBrainLib later if stable.
- Data-driven content under datapack-style JSON paths such as `data/ebb/dialogues`, `data/ebb/interactions/block_groups`, `data/ebb/interactions/entity_bindings`, `data/ebb/npc_routines`, `data/ebb/attributes`.

MVP order recommended by plan:

1. Project skeleton.
2. Block group highlight.
3. Entity bounding-box highlight.
4. HUD prompt.
5. Interaction request packet.
6. Static dialogue UI.
7. JSON dialogue tree.
8. d20 checks.
9. State persistence.
10. Developer viewer.
11. Human NPC / routine.
